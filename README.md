# 型に流し込む（pattern-fill-x）

投稿の骨組みを選ぶ（またはDay071「型ばらし」の骨組みの1行を貼る）と、書き出し・本文・締め・タグの欄が出ます。自分の言葉を入れると、空行つきの下書きがそろい、欄ごとに型に合っているかの目安が出ます（100日100プロダクト Day072）。

- 入れた文はブラウザの中だけで処理し、サーバーには送信せず、保存もしません（通信は閲覧数の計測のみ）
- AIは使っていません。文を作るのは利用者で、画面は欄を並べて連結するだけです（言い回しの提案・補完・例文なし）
- 型の見分けは目安で、外れることがあります。型と反応の関係は分かっていません
- 型の見分けはDay071と同じ規則です（検算でDay071と一致を確認）

## 開発用（source/）
- `index.src.html` と `wide-ranges.txt` から `build.py` が `index.html` を作ります
- `run-checks.js`: 骨組み・判定・下書きの検算（`node source/run-checks.js`）
- `e2e.js`: 実ブラウザ（Chrome headless）の検算。`peek.js`: 目視確認用の撮影
